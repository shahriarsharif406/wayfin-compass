# Business Case

> All numbers below are **illustrative assumptions** to show how the value is calculated. They are not measured results. Replace them with a company's real figures.

## The problem
Card disputes and travel disruptions generate long, repetitive support calls. Agents spend most of the call collecting the same details and explaining the same evidence list. Customers, often abroad and stressed, wait on hold.

## What Compass changes
| Before | With Compass |
|---|---|
| Agent asks every question from scratch | Pre-chat and workflows collect details before any human is involved |
| Customer unsure what proof is needed | Evidence checklist shown instantly for the exact dispute type |
| Case opened only during a call | Case opened in the chat with a number and next steps |
| Customer calls to ask "where is my case?" | Self-serve status check |
| Urgent cases wait in the same queue | P1 routing with a 15-minute target |
| Agent re-asks the story after transfer | Handoff summary travels with the customer |

## Simple ROI model (change the inputs)
| Input | Example value |
|---|---|
| Dispute and travel contacts per month | 10,000 |
| Share fully handled by Compass | 40% |
| Average agent handling time per contact | 12 minutes |
| Fully loaded agent cost per hour | USD 30 |

**Calculation:** 10,000 x 40% = 4,000 contacts x 12 minutes = 48,000 minutes = 800 hours x USD 30 = **USD 24,000 per month** in agent time. Contacts that still reach a person arrive with details already collected, which shortens those calls further.

## Metrics to track (all visible at `/dashboard`)
- Self-service rate
- Customer satisfaction (CSAT, 1 to 5)
- Handoffs and their priority mix
- Estimated agent minutes saved
- Time to case creation

## Why the design is practical
- Works on any website chat widget via the platform's published link.
- Policies live in plain documents the business already owns, so updating the bot means updating a document.
- Honest handoff keeps customer trust when the bot is unsure.
